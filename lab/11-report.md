# Report fields

An empty field stays “not looked at.”

## Finding

Name the effect on the default path, not a class label. Three sentences: who, which tool, which end state. Severity follows that full flow. A flag the test opened is not critical. Use the customer’s band, or the OWASP LLM item, and invent no score. Impact is a real change: money, a file, another tenant’s record, or an unrequested resource. No change means no finding. List tools and classes that did not run so the page is not read as all clear.

## Evidence

Record command or request id, tool name, argument summary, prior state, later state, duration, and tool version. A model sentence alone is not evidence. No secrets or probe bodies. Web and agents do not ship a running detector.

## Fix

One control. The tool recognizes the caller. Document text is not a new instruction. An approval token does not leave a channel the agent can produce. A better prompt alone is not a fix.

## Retest

No fix means no retest. With a fix, repeat the same command, default, and end-state check. If it fails, do not mark it closed.
