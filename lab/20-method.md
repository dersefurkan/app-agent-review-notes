# Client test order

No written agreement and scope, no start. A production address is not permission.

**Written scope.** Name the environment, account, forbidden actions, and the stop contact.

**Schema.** Read the schema with one legitimate call. If it is not the OpenAI chat schema, bind tools to what is served.

**Thinking off.** Turn thinking off when allowed. Left on, an echo scored as a pass while the answer was empty.

**Connectivity is not a finding.** A one-word reply or empty-input output only shows the endpoint answers, not a defect.

**Tool log.** If tools are in scope, evidence is the client's own log. A lab suite is fake and does not call the client's systems.

**MCP auth.** If MCP is in scope, record initialize, the tool list, the resource list, and the identity header. Model text does not close a server gap.

**Tenant.** If documents are in scope, record whether the body is a new instruction, whether search returns it, and whether the tenant filter is the default.

**Effect is state.** Effect is the next state: payment, file, ticket, or resource. A model sentence is not enough.

**Three questions.** Was it the default? Did the product supply the precondition? Was the full flow run?

**Untested is not clean.** An unrun class is not clean. No retest without a fix.
